Rules:
  • Each question starts with a number followed by a period or parenthesis
  • Options start with a letter (a, b, c, d…) followed by a parenthesis
  • The correct answer is on a line starting with "Answer:" followed by the option letter
  • Leave a blank line between questions
  • The document must be publicly accessible ("Anyone with the link can view")
